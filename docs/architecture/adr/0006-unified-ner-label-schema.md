# 6. Единая схема NER-меток с расширением для казахского

Date: 2026-11-18

## Status

Accepted

## Context

KazNERD содержит 25 классов, WikiANN — только PER/ORG/LOC. Прямое объединение даёт противоречивую разметку. Кроме того, в WikiANN нет класса DATE, значит модель не сможет выучить даты для ru/en.

## Decision

Обучаемая модель распознаёт общее ядро `PER, ORG, LOC` на всех трёх языках; отображение классов KazNERD задаётся в `configs/labels.yaml`. `DATE` извлекается отдельным rule-based экстрактором (регулярные выражения + `dateparser` для kk/ru/en) и оценивается на DATE-разметке KazNERD. Полная схема KazNERD-25 — отдельный эксперимент (NER-3).

## Consequences

Сопоставимые метрики между языками; расширенные классы не блокируют MVP.
